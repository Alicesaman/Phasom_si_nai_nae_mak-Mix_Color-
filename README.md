## Overview
ยุคดิจิทัลปัจจุบัน ภาวะสมาธิสั้น การเสพติดโซเชียลมีเดีย และประสิทธิภาพความจำระยะสั้นที่ลดลง กลายเป็นปัญหาสำคัญที่ส่งผลกระทบต่อสมาธิในการทำงาน ความสัมพันธ์ทางสังคม และสุขภาพจิตของผู้คนจำนวนมาก โครงงานนี้จึงพัฒนา **"เกมผสมสี"** ขึ้นเป็นสื่อสันทนาการแบบจับต้องได้เพื่อเป็นทางเลือกในการทำกิจกรรมออฟไลน์แบบลดการใช้หน้าจอ

ตัวเกมจำลองระบบแข่งขันความเร็วและการรู้คิด สำหรับผู้เล่น 2 คน โดยระบบจะสุ่มแสดงสีเป้าหมายขึ้นที่ไฟ LED กลางบอร์ด ผู้เล่นทั้งสองฝ่ายต้องประมวลผล จำแนกสูตรการผสมแสงสี และใช้ปุ่มกดผสมสีของตนเองให้ถูกต้องและรวดเร็วที่สุด โดยมีระบบนับคะแนนผ่านไฟ LED แสดงผล และจอ LCD แจ้งเตือนสถานะการแข่งขันแบบ Real-time ซึ่งช่วยกระตุ้นการโฟกัส ฟื้นฟูความจำระยะสั้น พัฒนาปฏิกิริยาตอบสนองของร่างกายและส่งเสริมปฏิสัมพันธ์ระหว่างบุคคลรอบข้างอย่างสร้างสรรค์

## Objectives
1. เพื่อออกแบบและพัฒนาระบบเกมสันทนาการเชิงกายภาพ สำหรับผู้เล่น 2 คน โดยบูรณาการการทำงานร่วมกันระหว่างไมโครคอนโทรลเลอร์ ปุ่มกด และระบบแสดงผล LED/LCD
2. เพื่อช่วยลดพฤติกรรมการเสพติดโซเชียลมีเดียและส่งเสริมการมีปฏิสัมพันธ์ทางสังคม\ระหว่างผู้เล่นผ่านกิจกรรมออฟไลน์
3. เพื่อฝึกทักษะการโฟกัสจดจ่อ การดึงข้อมูลความจำ และพัฒนาความเร็วของปฏิกิริยาตอบสนอง

## รายการอุปกรณ์และเครื่องมือที่ใช้

### 1. อุปกรณ์ฮาร์ดแวร์และโมดูล (Hardware & Modules)
* **Microcontroller Board:** Arduino UNO หรือ Arduino Nano (ประมวลผลหลักและควบคุมตรรกะเกม)
* **Input Devices:**
  * ปุ่มกด Push Button (Tactile / Arcade Button) รวม 6 ปุ่ม (ปุ่ม R, G, B สำหรับ Player 1  3 ปุ่ม และ Player 2 จำนวน 3 ปุ่ม)
* **Display & Visual Output:**
  * จอ LCD 16x2 พร้อม I2C Interface (แสดงสถานะเริ่มเกม นับถอยหลัง และประกาศผู้ชนะ)
  * RGB LED 7 สี รวม 3 จุด (โจทย์สุ่มตรงกลาง 1 ดวง และแสดงสีที่กำลังผสมของผู้เล่นทั้งสองฝั่งละ 1 ดวง)
  * หลอด LED สีแดง 6 ดวง (แสดงแต้มสะสม ฝั่งละ 3 ดวง)
  * passive buzzer modules 1 ตัว
* **Power Supply:** สาย USB หรือ แบตเตอรี่พกพา (เช่น รางถ่าน 9V)
* **วงจรสนับสนุน:** Resistors ขนาด 220Ω 

### 2. ซอฟต์แวร์ไลบรารี (Software Libraries)
* **`LiquidCrystal_I2C.h`**
* **`ezButton.h` หรือ `Bounce2.h`** 

### 3. เครื่องมือและอุปกรณ์ประกอบวงจร (Tools & Fabrication)
* เบรดบอร์ด (Breadboard) และสายจัมเปอร์ (Jumper Wires) สำหรับต่อวงจรต้นแบบ

## Game FlowState 
* **State 1: Ready**
  * หน้าจอ LCD แสดงข้อความ Hold Button to Start หรือกดปุ่มเริ่ม
  * เมื่อกดเริ่ม LCD นับถอยหลัง Ready 3.. 2.. 1.. GO!
* **State 2: สุ่ม 2 รูปเเบบ โจทย์สี**
  * 1.Mix Color บอร์ดสุ่ม 1 สีจาก 7 สี (R, G, B, Y, M, C, W) แล้วสั่งให้ LED กลางสว่างเป็นสีนั้น
  * 2.Memory Time บอร์ดสุ่ม 2-4 สีจาก 7 สี เเสดงเป็นลำดับ ให้ผู้เล่นกดให้ถูก
* **State 3: ผู้เล่นผสมสี**
  * ผู้เล่นกดผสมสี ปุ่ม R/G/B จะสะท้อนไปที่ไฟ LED ของตัวเองทันที เพื่อให้เห็นว่าผสมสีอะไรอยู่
  * การตรวจคำตอบแบบกดค้างพร้อมกัน ผู้เล่นกดปุ่มตามสูตรสีค้างไว้ให้ตรงกับโจทย์ ระบบเช็กว่าใครผสมถูกเป็นคนแรก
* **State 4: การให้แต้ม**
  * ผู้ที่ตอบถูกและไวกว่า จะได้แต้ม:
  *ถ้าฝ่ายตรงข้ามมีเเต้ม สั่งปิดไฟ LED สีแดงของฝั่งตรงข้าม
  *ถ้าฝ่ายตรงข้ามไม่มีเเต้ม สั่งเปิดไฟ LED สีแดงของฝั่งตัวเอง
* **State 5: เช็คผู้ชนะ**
  * ตรวจสอบว่ามีใครติดไฟแดงครบ 3 ดวงหรือไม่หากยังไม่ครบ
        * หน่วงเวลาเล็กน้อยแล้วกลับไป State 2 (สุ่มสีใหม่)
        * หากครบ 3 ดวง: จอ LCD แสดงผู้ชนะ (Player 1 Wins! หรือ Player 2 Wins!) พร้อมกระพริบไฟฉลอง และรอรีเซ็ตเกมใหม่
