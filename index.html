Abstract

บทคัดย่อ

ตัวเกมจำลองระบบแข่งขันความเร็วสำหรับผู้เล่น 2 คน โดยระบบจะสุ่มแสดงสีเป้าหมายขึ้นที่ไฟ LED กลางบอร์ด ผู้เล่นทั้งสองฝ่ายต้องประมวลผล จำแนกสูตรการผสมแสงสี และใช้ปุ่มกดผสมสีของตนเองให้ถูกต้องและรวดเร็วที่สุด โดยมีระบบนับคะแนนผ่านไฟ LED แสดงผล และจอ LCD แจ้งเตือนสถานะการแข่งขันแบบ Real-time

Game Flow State

ลำดับการทำงานของเกม

  1. STATE 1

    Ready

    • จอ LCD แสดงข้อความ Hold Button to Start หรือกดปุ่มเริ่ม
    • เมื่อกดเริ่ม LCD นับถอยหลัง Ready 3.. 2.. 1.. GO!
  2. STATE 2

    สุ่มโจทย์สี 2 รูปแบบ

    • Mix Color บอร์ดสุ่ม 1 สีจาก 7 สี (R, G, B, Y, M, C, W) แล้วสั่งให้ LED กลางสว่างเป็นสีนั้น
    • Memory Time บอร์ดสุ่ม 2–4 สีจาก 7 สี แสดงทีละสีตามลำดับ ให้ผู้เล่นกดตามให้ถูก
  3. STATE 3

    ผู้เล่นผสมสี

    • ปุ่ม R/G/B สะท้อนไปที่ LED ของผู้เล่นทันที เห็นได้เลยว่ากำลังผสมสีอะไรอยู่
    • ตรวจคำตอบแบบกดค้างพร้อมกัน ผู้เล่นกดปุ่มตามสูตรสีค้างไว้ให้ตรงกับโจทย์ ระบบเช็กว่าใครผสมถูกเป็นคนแรก
  4. STATE 4

    การให้แต้ม

    ผู้ที่ตอบถูกและไวกว่าได้แต้ม แบบชักเย่อ

    • ถ้าฝ่ายตรงข้ามมีแต้ม: ปิดไฟ LED แดงของฝั่งตรงข้าม 1 ดวง
    • ถ้าฝ่ายตรงข้ามไม่มีแต้ม: เปิดไฟ LED แดงของฝั่งตัวเอง 1 ดวง
  5. STATE 5

    เช็คผู้ชนะ

    • ยังไม่มีใครติดไฟแดงครบ 3 ดวง: หน่วงเวลาเล็กน้อย ↺ กลับไป STATE 2
    • มีคนครบ 3 ดวง: LCD แสดง Player 1 Wins! หรือ Player 2 Wins! กระพริบไฟฉลอง แล้วรอรีเซ็ตเกมใหม่
